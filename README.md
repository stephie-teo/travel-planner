# ✈️ Travel Planner

A responsive and collaborative travel planning web application built with **React, JavaScript, and Firebase**.

Travel Planner helps users organize their itineraries, manage travel budgets, save destinations, prepare travel checklists, and collaborate with friends or family in one centralized platform.

## ✨ Key Features

### 🔐 User Authentication
- User registration and login with Firebase Authentication
- Persistent login sessions
- Personal travel data associated with individual accounts

### 🗺️ Trip & Itinerary Management
- Create and update trip details, including destination, travel dates, and budget
- Add, edit, and delete itinerary activities
- Organize travel plans through an interactive dashboard

### 💰 Expense Tracking
- Record planned and actual expenses
- Automatically calculate total spending and remaining budget
- Categorize expenses for better financial visibility
- Support personal and shared group expenses

### 📍 Places & Travel Preparation
- Save and manage places to visit
- Create and update travel checklists
- Store essential travel information

### 👥 Group Collaboration
- Create travel groups and invite members using invitation codes
- Manage shared itineraries and expenses
- Synchronize group data across multiple user accounts in real time
- Apply owner-only permissions to shared trip settings

### 📱 Responsive UI
- Responsive layouts for desktop and mobile
- Consistent navigation and interface components
- Clean blue-and-white visual design

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- A Firebase project with Authentication and Cloud Firestore configured

### Installation

1. Clone this repository.
2. Open the project directory.
3. Run `npm install`.
4. Configure Firebase using your own project credentials and settings.
5. Start the development server with `npm run dev`.

> Ensure that your Firebase Authentication settings and Firestore Security Rules are configured appropriately before using the application.
